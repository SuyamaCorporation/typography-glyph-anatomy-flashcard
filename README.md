# Typography Glyph Anatomy Flashcard Trainer

Spaced-repetition flashcard quiz on 25 typographic terms with confidence-based mastery tracking.

## Key Features

- 25 cards covering all major typographic anatomy terms (serif, ascender, counter, ligature, stress axis, etc.)
- Card flip animation reveals definition and example letterform on the back
- Three confidence ratings (Again / Good / Easy) advance mastery level per card (0–3 scale)
- Colour-coded mastery grid (red → yellow → green → blue) with jump-to-card navigation
- localStorage persistence; progress survives page reloads; shuffle button randomises order
